# System setup

Portable developer setup for Ubuntu GNOME. Use [SETUP.md](SETUP.md) as the single installation checklist.

`dotfiles/` holds only your configuration changes in a future-ready Stow layout. It is not part of the current setup instructions: LazyVim stores just its added plugins and overrides, and Fish stores only custom interactive settings plus its Fisher plugin list.

Update `SETUP.md` when your setup changes. Before committing, inspect staged changes; do not add sensitive or generated data.
